# doc-mk/slides: DP PPT 작성 기준

> 다른 세션에서 DP(DP1~DP4) 설계 PPT를 만들 때 **먼저 이 문서와 기준 파일을 참고**한다. 사용자가 이 스타일을 지정했다(2026-10-10). `.claude/skills/architect-presentation`의 정한웅/유상욱 BP 스타일보다 **이 프로젝트 스타일이 우선**한다.

## 스타일 규칙 (기준 파일에서 관찰)

- 16:9(13.333 × 7.5 in), 흰 배경, 폰트 **맑은 고딕**. 본문 10~12pt, 다이어그램 라벨 7~10pt로 조밀하다.
- **제목**: 좌상단 `DPn. 제목 - 배경 / 설계 / ...`, 굵게. 제목 아래·위에 가는 구분선(레이아웃 `1_제목 및 내용`에 포함).
- **상단 내비게이션**: 우상단 chevron 5개 `과제 소개 / 요구사항 / 설계 / 구현/검증 / 결론`. 현재 단계는 진한 회색(`595959`), 나머지는 연한 회색(`BFBFBF`), 글자 흰색 10pt 굵게. 기준 레이아웃의 내비는 고정이라 **슬라이드마다 직접 그린다**.
- **페이지 번호**: 하단 중앙 `n / 총장수`. 레이아웃의 `/ 23` 텍스트는 총장수에 맞게 바꾼다.
- **배경 슬라이드**: 상단에 `-` 글머리 설명 12pt(`404040`), 점선 패널(`BFBFBF`) + 위에 걸친 둥근 라벨(`F2F2F2` 바탕, 굵게 12pt), 하단에 파란 오른쪽 화살표 + 핵심 메시지(`0066FF` 굵게 12pt), 그 아래 `설계 쟁점 1. / 2.`(굵게 11~12pt).
- **설계 슬라이드**: 제목 아래 회색 띠(`7F7F7F`)에 결정 질문(흰색 굵게 14pt), 우측에 칩. 칩 색: **F(기능 요구사항) `203864` / Q(QA) `833C0B` / C(제약) `375623`**, 흰 굵게 9pt.
- **후보 비교 표**: 열 `[행 라벨 | 1안 | 2안]`, 행 `설계 안 / 구조 / 장점 / 단점 / Tradeoff`. 행 라벨은 회색 글자 가운데 정렬, 표 경계는 가는 회색(`BFBFBF`). 안 제목은 `(1안) 설명 + 강조`에서 강조를 빨강으로. 단점의 핵심은 빨강. **구조 행에는 도식을 표 위에 겹쳐 그린다**. 선택된 안은 빨간 테두리, 평가 전이면 표시하지 않는다.
- **도식 색**: 파랑 `2E75B6`/`DEEBF7`, 주황 `C55A11`/`FBE5D6`, 초록 `548235`/`E2F0D9`, 회색 상자 `F0F1F3`, 노랑 강조 `FFF2CC`/`BF9000`. 연결선 `7F7F7F` 1pt, 점선은 비동기·수집·제어 흐름. 컨테이너는 위쪽에 진한 색 제목 띠.

## 내용 규칙 (이 프로젝트)

- 평가 전 결과는 **`[가설]`, `[추정]`, `[가정]`** 으로 표시하고 실측·시뮬레이션 `[B+C]`과 구분한다. 근거 없는 숫자를 만들지 않는다.
- **별점·점수는 정량 구간이 정의되기 전에는 쓰지 않는다**(통합 단계에서 임계값 확정, `Requirements/memo-threshold-unification.md`). 기준 파일의 별점 표시는 참고용이다.
- QA는 현재 DP2 기준 Q1(Throughput) · Q2(Latency) · Q3(Resource Utilization = HBM 점유율, 낮을수록 좋음)이다. 각 DP의 QA 선정은 `Requirements/` 문서를 따른다.
- 발표 노트는 `핵심 → 근거 → 선택의 의미` 순서로 짧게 쓴다. 출처 문서 경로를 노트나 하단에 적는다.

## 만드는 방법

1. `.venv`(uv)에 `python-pptx`를 설치한다. 시스템 python은 쓰지 않는다.
2. `reference/build_dp_deck_example.py`의 헬퍼(`new_slide`, `band`, `dashed`, `container`, `table`, `keymsg`, `pageno`)를 재사용하고 슬라이드 정의부만 바꾼다. 기준 pptx를 템플릿으로 열어 슬라이드를 지우고 레이아웃 `1_제목 및 내용`으로 추가한다.
3. LibreOffice로 PDF로 변환해 모든 장을 렌더링해 확인한다(맑은 고딕이 없으면 대체 폰트로 렌더되므로 줄바꿈 여유를 둔다). 표 행이 늘어나 아래 도형과 겹치지 않는지 본다.
4. 기준 pptx(약 4.7MB)는 수정하지 않는다. 새 덱은 다른 파일명으로 저장한다.
