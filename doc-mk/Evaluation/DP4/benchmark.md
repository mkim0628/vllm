# 5. fit 분류 규칙

comparison-valid / infeasible / saturated (SKILL §4, 공통 문서 §4). saturated는 이득 근거가 아니다. 분류는 결과를 보기 전 SLO 기준으로 하며 `qa_eval.py`가 자동 부여한다(`label_scenarios`).

# 6. 모델링하지 않는 시나리오

CXL 풀 장치 장애·오류, 스위치 혼잡(집계 BW 상한만), 다중 테넌트 격리(문헌에서도 공백), KV 외 객체(LoRA/MoE/Agent/Tool)별 접근 패턴의 차이(CB-3은 풀 트래픽·객체 수 비율만 반영), 균일 분포 접근 전용 시나리오, 실제 trace.
