# BP 스타일 규칙

> **프로젝트 DP PPT는 `doc-mk/slides/README.md`와 `doc-mk/slides/reference/DP-PPT-style-reference.pptx`(사용자 제공, 2026-10-10)를 먼저 따른다.** DP1~DP4 설계 슬라이드를 만들 때는 아래 정한웅/유상욱 BP 스타일보다 그 스타일이 우선한다. 아래 내용은 BP 형식을 직접 요청받았을 때와 논증 흐름 참고용이다.

## 선택과 출처

정한웅 PPT를 기본 시각 스타일로 사용한다. 유상욱 PPT의 대안 비교와 요구사항 추적 방식을 보조로 사용한다. 두 스타일의 장식을 슬라이드마다 임의로 섞지 않는다. 아래는 실제 OOXML 확인과 전체 55/39장 시각 검토에 근거한 관찰이다. 원본의 작은 글씨를 개선하는 권장값은 관찰값과 구분했다.

## 공통 관찰

- 두 PPT의 캔버스는 12,192,000 × 6,858,000 EMU, 즉 13⅓ × 7.5 inch, 16:9다. 96 DPI 도구에서는 1280 × 720 px에 해당한다.
- 본문은 흰색이며 구조도, 요구사항 표, 후보 비교, 평가 근거를 밀도 있게 배치한다.
- 한국어 본문은 주로 맑은 고딕, 일부 영문은 Calibri/Arial이다. 코드에는 Courier New도 사용한다. 테마 폰트 토큰(+mn-ea 등)은 실제 글꼴 이름이 아니다.
- FR, QA, 제약 ID를 설계 페이지와 Coverage 표에 반복해 추적 가능하게 한다.
- 상단 진행 내비게이션과 페이지 번호를 사용하고, 상세 근거는 Backup/Appendix로 분리한다.

## 생성할 때의 가독성 조정

원본은 도식 내부에 7–12pt 텍스트가 많다. 이 밀도를 새 발표에서 무조건 재현하지 않는다. 헤더와 레이아웃 정체성을 유지하면서 본문 14–18pt, 중요 도식 라벨 12–16pt를 우선한다. 복잡한 도식은 전체 구조 + 상세 페이지로 나누고, 고정 장수일 때는 부가 설명을 노트로 옮긴다. 정확한 원본 복제가 명시된 경우 원본 크기를 보존하되 읽기 어려운 부분을 알린다.

권장 안전 여백은 좌우 0.26–0.35 inch, 하단 0.25–0.35 inch다. 이 값은 생성 권장값이며 모든 원본 객체의 정확한 좌표를 뜻하지 않는다. 제목·본문·표의 실제 기하 정보는 `inspect_deck.py`와 원본 렌더로 확인한다. 1pt=1⅓px, 914,400 EMU=1inch를 사용한다.

사진·반도체 제품·로고는 원본에 있다고 자동으로 복제하지 않는다. 새 과제의 설명에 필요한 소재만 출처와 함께 사용한다. 장식용 이미지보다 구조·관계·근거의 가독성을 우선한다.
